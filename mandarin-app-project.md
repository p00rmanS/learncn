# 声 Shēng — A Mandarin App for Absolute Beginners

> Working title. 声 (shēng) means "sound/voice," because the whole app is built on getting the sounds right first.

## 1. Why this exists

The goal is to take someone with **zero Mandarin** to holding simple real conversations and reading basic text (roughly HSK 2–3 level) in about 6 months of 20–30 minutes a day.

It is deliberately **not Duolingo**. Common frustrations with Duolingo-style apps, and what this app does instead:

| Duolingo-style problem | This app's answer |
|---|---|
| Streaks, hearts, guilt notifications | No streaks, no lives, no shaming. One calm daily session that ends when it's done. |
| Random, weird sentences ("The bear drinks beer") | Every sentence is something you'd actually say or hear. |
| Grammar is never explained, you guess until it clicks | Short, plain-English notes before you practice a pattern. |
| Tones treated as an afterthought | Tones and pronunciation are the foundation — taught first, practiced daily, checked with a pitch graph. |
| Characters are memorized as random pictures | Characters are broken into components (radicals) with meaning and sound hints. |
| Lots of tapping word tiles, little real listening | Heavy listening, shadowing (repeating audio out loud), and graded stories. |
| Hard to know what you actually remember | Spaced repetition (FSRS) schedules reviews exactly when you're about to forget. |

## 2. Who it's for

- **Primary user:** an adult beginner with zero knowledge who wants to understand *why*, not just tap buttons.
- Studies on phone and laptop, 20–30 min/day.
- Wants spoken ability first, reading second, handwriting optional.

## 3. Learning philosophy

1. **Sound before symbols.** Weeks 1–2 are only pinyin and tones. Bad tone habits are very hard to fix later.
2. **Comprehensible input.** Lots of listening and reading at a level just slightly above you.
3. **Active recall + spaced repetition.** You recall answers instead of recognizing them, on an algorithm-driven schedule.
4. **Chunks over isolated words.** Learn 你叫什么名字？ as a unit, then break it down.
5. **Characters as systems.** 好 = 女 (woman) + 子 (child) → "good." 妈 = 女 (meaning: female) + 马 (sound: mǎ).
6. **Speak out loud every session.** Shadowing builds rhythm and tones faster than silent study.

## 4. Curriculum roadmap

### Phase 0 — Sound System (Weeks 1–2)
- The 4 tones + neutral tone, with pitch contours: ā (high, flat) · á (rising) · ǎ (low, dipping) · à (falling) · a (light, short).
- Initials (b, p, m, f … zh, ch, sh, r, j, q, x, z, c, s) and finals (a, o, e, ai, ei, ao, ou, an, en, ang, eng, ong, i, u, ü …).
- Tricky pairs: j/q/x vs zh/ch/sh vs z/c/s; ü vs u.
- **Tone pair drills:** all 20 two-syllable tone combinations (e.g. 中国 zhōngguó = 1+2, 你好 nǐ hǎo = 3+3).
- Tone change rules: 3+3 → 2+3 (你好 is said *ní hǎo*); 不 bù → bú before a 4th tone; 一 yī changes by context.
- **Milestone:** read any pinyin aloud correctly and hear the tone of a syllable ~80% of the time.

### Phase 1 — Survival Core (Weeks 3–8) ≈ HSK 1
- ~300 high-frequency words, ~150 characters, top 50 radicals.
- Core patterns:
  - 我是… (I am…) / 你叫什么名字？(What's your name?)
  - …吗？ yes/no questions
  - 不 vs 没 (negation)
  - 有 / 没有 (have / don't have)
  - 这是什么？(What is this?)
  - Numbers, dates, time, money (多少钱？)
  - Measure words, starting with 个
- Topics: greetings, self-introduction, family, food & ordering, numbers & shopping, time.
- **Milestone:** introduce yourself, order food, ask prices, understand slow simple speech.

### Phase 2 — Building Blocks (Months 3–6) ≈ HSK 2–3
- ~1,200 words, ~600 characters.
- Patterns: 了 (completion/change), 过 (experience), 在 + verb (in progress), 想/要/会/能 (want/will/can), 比 comparisons, 因为…所以…, basic 把.
- Graded stories (300–800 characters each) with audio.
- **Milestone:** 5-minute simple conversation; read a short graded story with ~95% known words.

### Phase 3 — Real Language (Month 6+)
- Native-speed listening clips, longer stories, conversation prompts, opinion questions.

## 5. Core features

### 5.1 Sound Lab (pronunciation)
- Interactive pinyin chart: tap any syllable in any tone to hear it.
- **Pitch visualizer:** records your voice, draws your pitch line on top of the native speaker's line so you can *see* if your 3rd tone dips enough.
- Tone ear-training: hear a syllable or word → pick the tone(s).
- Minimal-pair drills (mā/mǎ, shì/sì, qù/cù).

### 5.2 Daily Session (the main loop, ~20 min)
A fixed, predictable structure — no endless feed:
1. **Warm-up (2 min):** 5 tone-pair listening drills.
2. **Reviews (8 min):** due spaced-repetition cards.
3. **New material (6 min):** 5–8 new words/chunks introduced in context, with a short grammar note if needed.
4. **Shadowing (3 min):** listen and repeat one dialogue line by line.
5. **Done screen:** what you learned today. No streak counter.

### 5.3 Spaced Repetition (SRS)
- Algorithm: **FSRS** (modern successor to Anki's SM-2).
- Card types per word:
  - Listen → meaning (audio only)
  - Character → pinyin + meaning
  - Meaning → say it out loud (self-graded, optional pitch check)
  - Sentence cloze (fill the missing word)
- Grading: Again / Hard / Good / Easy.
- Daily new-card cap is adjustable; reviews never "punish" you for missing a day.

### 5.4 Character Lab
- Stroke-order animation and optional tracing quiz.
- Component breakdown: each character shows its parts, which part hints meaning, which hints sound.
- "Character family" view: 马 → 妈 吗 骂 码 (shared sound component).

### 5.5 Stories Reader
- Graded stories unlocked by your vocabulary.
- Tap any word → pinyin, meaning, audio, "add to SRS."
- Toggle pinyin on/off; toggle characters vs pinyin-only for early phases.
- Highlights words you're currently learning.

### 5.6 Grammar Notes
- One-screen explanations in plain English with 3–5 examples each, linked from lessons.
- Example: *"了 often marks that something is done or has changed. 我吃了 = I ate. 下雨了 = It's raining now (it wasn't before)."*

### 5.7 Progress (calm, honest)
- Words known, characters known, estimated HSK level, minutes listened.
- A heatmap of study days with **no streak count and no broken-streak alerts.**
- One optional gentle daily reminder at a time you choose.

## 6. Tech stack

| Layer | Choice | Why |
|---|---|---|
| App | React + TypeScript + Vite | Fast, simple, huge ecosystem |
| Platform | Progressive Web App (PWA) | Works on phone + laptop, installable, offline |
| Styling | Tailwind CSS | Quick, consistent UI |
| Local data | IndexedDB via Dexie.js | Offline-first storage for cards and progress |
| SRS | `ts-fsrs` | TypeScript FSRS implementation |
| Stroke order | `hanzi-writer` | Stroke animations + tracing quizzes |
| Pinyin | `pinyin-pro` | Character → pinyin with tone marks |
| Audio (TTS) | Web Speech API (zh-CN voice) to start; pre-recorded/neural TTS later | Free to start, upgrade for quality |
| Pitch detection | Web Audio API + `pitchy` | Draw the user's pitch contour |
| Sync (later) | Supabase (auth + Postgres) | Cross-device sync once the core works |

## 8. Data model (draft)

```ts
type Word = {
  id: string;
  hanzi: string;          // 你好
  pinyin: string;         // nǐ hǎo
  meanings: string[];     // ["hello"]
  hskLevel: number;       // 1
  audioUrl?: string;
  characterIds: string[];
};

type Character = {
  id: string;
  hanzi: string;          // 好
  pinyin: string[];       // ["hǎo", "hào"]
  meaning: string;
  components: { part: string; role: "meaning" | "sound" | "other" }[];
};

type Sentence = {
  id: string;
  hanzi: string;
  pinyin: string;
  english: string;
  wordIds: string[];
  audioUrl?: string;
};

type Card = {
  id: string;
  wordId: string;
  kind: "listen" | "read" | "produce" | "cloze";
  fsrs: { due: Date; stability: number; difficulty: number; reps: number; lapses: number; state: number };
};

type ReviewLog = {
  cardId: string;
  rating: 1 | 2 | 3 | 4;   // Again, Hard, Good, Easy
  reviewedAt: Date;
  elapsedMs: number;
};

type Lesson = {
  id: string;
  phase: 0 | 1 | 2 | 3;
  title: string;          // "Ordering food"
  grammarNoteIds: string[];
  newWordIds: string[];
  dialogueSentenceIds: string[];
};
```

## 9. Screens

1. **Home** — "Start today's session" button, today's estimate (e.g. 18 min), quick links to Sound Lab / Stories.
2. **Session** — the 5-step daily loop.
3. **Sound Lab** — pinyin chart, tone drills, pitch visualizer.
4. **Characters** — browse learned characters, components, stroke practice.
5. **Stories** — library filtered by your level.
6. **Grammar** — searchable list of notes.
7. **Progress** — stats and calm heatmap.
8. **Settings** — daily new cards, reminder time, pinyin display, voice speed.

## 12. How we'll know it works

- After 2 weeks: you can read pinyin aloud and identify tones ≥ 80%.
- After 8 weeks: ~300 words known with ≥ 85% review retention.
- You *want* to open it — measured by honest self-check, not by streaks.
